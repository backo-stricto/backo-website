# website for backo

[https://backo-stricto.github.io/backo-website/](https://backo-stricto.github.io/backo-website/)


## Installation and build

[install zola](https://www.getzola.org/documentation/getting-started/installation/)

# To run localy

```bash
cd backo
zola serve
```

# To build

```bash
cd backo
zola build
```
